# Thesis Data Visualization: Consumer Preference & Conjoint Analysis

This repository contains the Python scripts utilized to programmatically generate academic data visualizations for my Bachelor's thesis in Industrial Engineering at Universitas Tarumanagara.

## Research Context
- **Thesis Title**: Analisis Preferensi Konsumen Menggunakan Pendekatan Metode Conjoint Analysis & QFD (Studi Kasus PT. Boga Dimsum Indonesia)
- **Object of Study**: Frozen Food Product (Bakpao)
- **Methodology**: Conjoint Analysis integrated with Quality Function Deployment (QFD)
- **Data Collection**: Questionnaire field survey from 100 targeted respondents in Jakarta, Indonesia.

## Repository Purpose
While the core multi-variate statistical processing was initially structured via SPSS, this specialized Python script was developed using `pandas`, `matplotlib`, and `seaborn` to build clean, high-resolution, reproducible visual charts for the thesis appendix and documentation layout.

## Visualized Parameters
1. **Demographic Profiling**: Distribution of survey respondents by gender alignment.
2. **Conjoint Attribute Importance**: Relative attribute importance levels (ranking from the most crucial factor, *Container Shape*, down to the *Tear Notch Opening Mechanism*).
